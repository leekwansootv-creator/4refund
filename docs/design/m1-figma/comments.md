# 댓글 수집 기록

2026-10-06 Chrome에서 해결된 댓글 포함, 내 스레드 제한 해제, 현재 페이지 제한 해제로 13개 스레드를 확인했다. 12개는 해결 상태, #13은 미해결 상태였다. 모두 **메인 페이지**에 속한다. P0 CMS의 별도 요구사항으로 혼합하지 않는다.

P0 페이지에서 해결된 댓글 포함·현재 페이지만 필터를 적용했을 때 표시된 댓글은 없었다. 이는 해당 계정으로 접근 가능한 UI에서 확인한 결과이며 삭제된/권한 밖 댓글까지 없다는 뜻은 아니다. 개발 주석은 댓글과 별도로 [주석 원문](annotations.md)에 정리했다.

근거: [전체 댓글 원문](evidence/comments-all.txt), [전체 필터](evidence/comments-all-filter.txt), [P0 필터](evidence/comments-p0-filter.txt), [P0 빈 댓글 패널](evidence/comments-p0.txt).

#1 답글은 진입 애니메이션/자동 반복이 없음을 지적하고 **아이템 하나당 1600ms**를 명시한다. 또 **1 → 4 순서로 선택이 자동 변경되는 무한 loop**라고 설명한다. [첨부 원본](evidence/comment-01-attachment.png)과 [확대 열람 화면](evidence/comment-01-attachment.jpg)을 함께 보관했다. 해결 표시 자체를 구현/실검증 완료로 간주하지 않는다.

메인 페이지의 실제 prototype 타이밍·easing·motion 트랙 전량은 이번 P0 자료 수집 범위에서 추출하지 않았다. 댓글 작성·답변·해결 상태 변경은 수행하지 않았다.
