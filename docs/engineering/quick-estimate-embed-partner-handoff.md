# 예상 환급액 조회 제휴사 전달 안내

이 문서는 **운영 공개 후 사용할 전달 기준**이다. 로컬 구현·검증 완료와 실제 운영 공개를 구분한다. 실제 접수 가능한 URL을 확인하기 전에는 “설치하면 상담 접수가 된다”고 안내하지 않는다.

## 전달 묶음

공개 후보의 `embed/partner/`에 아래 파일이 생성된다. 제공 URL·prefix·고정 버전은 같은 배포 설정에서 생성한다.

| 파일               | 제휴사 용도                                                     |
| ------------------ | --------------------------------------------------------------- |
| `install.html.txt` | 기본 권장: 컨테이너와 script를 붙이면 호환 업데이트 자동 적용   |
| `pinned.html.txt`  | 지정 버전 고정 코드                                             |
| `iframe.html.txt`  | script 불가 CMS의 iframe·별도 링크 대안                         |
| `demo.html`        | 실제 접수 없는 조회 예시. iframe 내부 모달 방식임을 화면에 표시 |
| `README.md`        | 최소 폭·HTTPS·CSP·출처·개인정보·장애 복구·책임 안내             |

소스 저장소, 전체 배포 archive, Google 시트·Apps Script 설정과 자격 증명은 전달하지 않는다. 브라우저에 로드되는 코드와 접수 주소까지 비공개라는 뜻은 아니며 우리가 유지보수를 담당한다.

## 공개 후 전달 메시지 예시

실제 주소는 공개 완료한 배포본에서 가져온다. 미확인 상태를 지운 채 전달하지 않는다.

> 포리펀드 예상 환급액 조회 기능의 설치 코드와 예시 페이지를 보내드립니다. 원하는 위치에 기본 코드를 넣고 가로 320px 이상의 공간을 확보해 주세요. 조회·상담 화면과 업데이트는 포리펀드가 관리합니다. 최종 상담 신청은 포리펀드 접수 시스템에 저장되며 설치 사이트를 함께 구분합니다. 별도 Google 설정이나 개발 소스 설치는 필요하지 않습니다.
>
> 조회 예시 페이지에서는 실제 상담 신청이 발생하지 않습니다. 실제 설치 코드의 최종 신청 버튼은 접수를 발생시키므로 설치 확인에서는 조회와 모달 표시까지만 확인해 주세요. 최종 저장 확인은 담당자와 합의한 범위에서 진행합니다.

## 설치 확인과 역할

1. 제휴사는 HTTPS 최상위 페이지에 기본 코드를 넣는다. CSP가 있으면 기존 허용 목록에 제공 origin의 script·frame·style을 추가한다.
2. 편지·버튼, 조회, 모바일 폭, 전체 화면 모달과 닫기·스크롤을 확인한다. CMS가 script를 삭제하면 iframe 또는 일반 링크를 사용한다.
3. 필요하면 `data-diagnostic="1"`로 준비 완료와 설치 사이트 주소를 확인한 뒤 제거한다. 이 주소는 인증 비밀이 아니다.
4. 실제 저장·알림은 포리펀드가 지정한 절차로 확인한다. 제휴 페이지가 개인정보를 별도로 받거나 모듈이 부모 페이지에 상담 정보를 반환하지 않는다.
5. 문제 발생 시 페이지 주소, 설치 방식·버전, 기기·브라우저, 오류를 전달한다. 개인정보가 담긴 화면은 가린다.

기본 제공은 도메인별 최종 상담 신청 구분이다. 이전 유입 페이지·전체 조회 이력·캠페인 분석은 포함하지 않는다. 제휴처·캠페인 ID는 설치 필수값이 아니며 별도 캠페인·정산·지원 기간 요구가 생길 때 추가 논의한다.

지원 조건과 수용량은 확인한 범위만 안내한다. 로컬 Chromium 검사를 모든 CMS나 iOS Safari·Android 실기기의 보장으로 바꾸지 않는다. 내부 운영·복구는 [출시·복구 절차](../operations/quick-estimate-embed-release.md)를 따른다.
