P0은 데스크톱 기준 고정형 화면입니다. 좁은 화면을 위한 별도 레이아웃 재배치나 모바일 화면은 현재 범위에 포함하지 않습니다.
단, 브라우저 뷰포트 너비가 1440px 미만이면 사이드바만 아이콘형으로 자동 축소합니다. 사용자는 토글 버튼으로 다시 펼칠 수 있습니다.
화면 너비가 부족해도 본문 정보와 표를 임의로 줄바꿈하거나 글자 크기를 축소하지 않습니다. 필요한 경우 해당 영역에 가로 스크롤을 적용합니다.
모든 목록의 최초 로딩은 목록 구조를 유지한 스켈레톤으로 표시합니다.
필수 입력이나 파일의 서버 수신 확인이 완료되기 전에는 다음 단계 또는 최종 접수 버튼을 비활성화합니다.
권한이 없는 메뉴·탭·버튼은 비활성화하여 노출하기보다 기본적으로 표시하지 않습니다.
