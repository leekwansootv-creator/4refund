카드 아래 안내는 `최근 보도자료 3건만 노출합니다.`이며 카드 그룹과 간격 4px, 14px regular / 1.6 / `rgba(27,38,78,0.5)`다. 관리 데이터의 제목·이미지·원문 URL을 연결한다. 원문 이동 방식과 게시 0건·1건·2건, 로딩·오류, 모바일 열 수는 기획의 제안·미결정 사항을 따른다. 날짜·언론사·요약·더보기 버튼은 관찰된 디자인에 없으므로 자동 추가하지 않는다.

## 팝업과 상태 및 모션

별도 봉투형 팝업은 480 × 553.062px, 흰색, 모서리 24px, 여백 28px, 그룹 간격 16px다. 로고는 폭 100px, 닫기 버튼 슬롯 24px, 제목은 Noto Sans KR black 26px / 1.3, 이미지 영역 높이 296.761px, 봉투 본체 295px다. 안내는 15px regular / 1.5, 버튼은 폭 424px·높이 53.893px다. 그림자 `0 12px 32px rgba(0,0,0,0.08)`를 사용한다. 용도·트리거가 미정이므로 디자인 보존과 기능 추가를 구분한다.

| 대상             | 확인된 상태·연결                              | 구현 시 처리                                              |
| ---------------- | --------------------------------------------- | --------------------------------------------------------- |
| Hero 조회        | hover 변경, 클릭 시 과거 담당자 입력 오버레이 | 과거 연결을 재현하지 않고 승인된 업종·직원 수 선조회 유지 |
| 혜택             | 마우스 진입·이탈에 따른 선택 변경             | 현행 키보드·touch·자동 순환과 일시정지 유지               |
| 메뉴·무료 진단   | hover와 섹션 스크롤                           | 기존 앵커·active·focus·모바일 정책 유지                   |

| 뉴스             | 이미지 유무 두 variant                        | 클릭·hover·focus·모바일·빈 상태는 기능 설계에서 확정      |
| 별도 봉투 팝업   | 닫기·조회 버튼의 외형                         | 자동 표시·재노출·전환은 미정                              |

모션 원문은 [motion.json](reference/motion.json)에 17개 노드와 타임라인으로 보존되어 있다. 종이는 Y 50px에서 원위치로, 동전은 상하, 사례는 X 0에서 약 -1900.805px로 이동한다. 혜택·전문가 문구 진입, 강점 이미지의 상하 이동, 절차 카드 1.08배 강조도 포함된다. 전체 Figma 주기는 약 28.02초이나 현행 절차 주기 8초를 자동으로 바꾸지 않는다. 원문의 키프레임은 시간·좌표 참고이며 실제 사용자 동작은 현행 구현 계약과 [interactions.json](reference/interactions.json)을 함께 따른다.

## 모바일과 검수

새 모바일 시안은 확보되지 않았다. 현재 `landing-responsive.module.css`의 반응형 정책과 `landing-motion.module.css`의 reduced motion을 유지하면서 새 두 인물 소개와 뉴스 카드에 적용한다. 신규 요소의 축소·쌓임·줄바꿈은 기획의 미결정 사항을 사용자와 확정한다. 데스크톱의 고정 높이·음수 margin·nowrap을 모바일에 복사하지 않는다.

검수는 각 로컬 섹션 화면, 상세 수치, 문구 색인, 이미지 슬롯을 대조한다. 전체 축소 캡처는 순서 확인용이고 섹션 캡처는 배치 확인용이다. 구현한 화면의 원본 치수·줄바꿈·크롭·키보드·모바일·모션을 따로 확인한다. 자동 검사 통과를 시각 일치의 증거로 대체하지 않는다.
