## 서로 다른 출처를 읽는 법

- SVG: 도형·글꼴 속성·문구·배치. 순수 그림만으로 동작이나 API 허용 여부를 추정하지 않는다.
- MCP: 노드 ID와 상세 스타일·컴포넌트 변형·개발 주석. sparse 응답은 구조 자료로만 취급한다.
- Dev Mode 주석 DOM: 화면 주변에 표시된 주석. 인접 섹션 주석도 포함될 수 있으므로 선택 영역에 모두 귀속시키지 않는다.
- 캔버스 TEXT: 별도 규칙으로 읽어야 한다. `894:19718` 공통 규칙, `493:1285` 역할 표, `923:20892` 접근 표, `942:21065` 입력 변경/이탈 설명을 명세에 반영했다.
- 댓글: 해결 상태·답글·작성 위치를 보존한다. 메인 페이지 댓글을 P0 CMS 기능에 그대로 적용하지 않는다.
- handoff: 2026-10-03 기준 계약·범위의 참고 자료. 현재 배포 환경이나 최신 main의 실검증 증거가 아니다.

## 남은 확인과 제한

1. 재시작 후 로컬 Figma MCP 도구가 현재 세션에 노출되지 않았고 원격 Figma 연결은 재인증 필요 오류를 반환했다. 추가 MCP 대상 12개는 [pending-mcp.json](evidence/pending-mcp.json)에 있다. 해당 인증 화면의 **SVG·문구·노드 구조는 확보**했지만 개별 MCP 상세 응답은 미확보다.
2. 최초 manifest 150개에 비해 실제 노드 원본은 174개다. 재시작 전에 추가 수집하던 중 중단되어 생긴 차이다. 조회 여부는 실제 파일과 새 catalog의 `mcp`·`sparse` 필드를 기준으로 한다.
3. 일부 상위 MCP 응답은 sparse이며 자식 노드를 추가 수집했다. 전체 숨김 레이어, 모든 인스턴스 override, 모든 prototype 연결과 motion 트랙의 완전한 복제는 아니다.
4. 14개라는 수치는 MCP에서 추출한 명시적 주석 수다. 브라우저에서 확인한 공통 목록 상태·배정 권한 등은 별도로 [화면 명세](screen-spec.md)에 반영했으므로 전체 Figma 주석 개수라고 해석하지 않는다.
5. 원본 SVG에는 외부 이미지 참조가 없고 폴더만으로 열람할 수 있다. 인증 SVG에는 `example.com/support` 예시 하이퍼링크 1개가 있지만 시각 렌더링용 외부 의존성은 아니다. 탐색기의 Figma 링크만 원격 서비스로 이동한다.
6. Pretendard 폰트 파일은 미포함이다. 로컬 글꼴 설치 여부에 따라 줄 길이·자형이 달라질 수 있다. SVG의 font-family·size·weight 원값은 보존했다.
7. 원본 MCP 코드의 임시 asset URL은 증거로 남겼다. 개별 프로덕션 아이콘 파일 전체를 별도로 내려받은 패키지는 아니며, 시각 열람에는 완전한 섹션 SVG를 사용한다. 앱 구현에서 임시 URL을 사용하지 않는다.
8. 대상은 링크가 가리키는 **P0와 M1 handoff 범위**다. P1·모바일·디자인·참고 페이지 전체, 공개 랜딩 전체 화면의 오프라인 복제는 포함하지 않는다. 댓글은 파일 전체에서 확인된 내용을 부록으로 수집했다.

## 갱신 방법

`extract-svg-text.py`는 보관 SVG의 텍스트·스타일·계층을 추출하며, `build-catalog.py`는 그 추출본과 MCP 원본만 읽는다. 새로운 원본을 추가한 뒤 인덱스·명세를 갱신한다. 원본 SVG를 수정하지 않고 스타일·문구 변경은 새 수집본의 해시와 비교한다. 자동 추출이 인간의 화면별 동작 검토를 대신하지 않는다.

노드 ID는 [노드 목록](node-catalog.md)에 있다. 로컬 MCP 서버 endpoint와 node ID는 별개다. 재연결 시 해당 파일을 열고 필요한 노드 ID를 도구 인자로 전달한다. 예: `923:20145`. `I...;...` 형식은 인스턴스 내부 식별자이므로 원본 응답의 상위 화면 노드도 함께 참조한다.

## 검증 기록

최종 검증 결과는 이 절에 실제 실행 결과만 기록한다. 디자인 자료 수집과 애플리케이션/RPA/운영 인수는 별개다.

- 로컬 생성기 실행: SVG 11개 파싱, 외부 이미지 참조 0개, 탐색 항목 198개 생성 확인.
- Chrome에서 로컬 HTTP로 목록·상세·중첩 인증 SVG 렌더링, 노드 ID 검색, 문구+영역 필터, 빈 결과, 원본 크기 전환, 주석 표시를 확인했다. 브라우저 오류/경고 로그는 없었다. [열람 화면](evidence/offline-viewer.jpg).
- 탐색 항목 198개의 SVG/MCP 파일 참조, 최상위 Markdown의 로컬 링크, SVG 영역 좌표의 경계를 검사해 누락·범위 초과 0개를 확인했다.
- 자동 브라우저의 URL 정책상 `file:` 직접 열기는 허용되지 않아 더블클릭 실행은 자동 검증하지 못했다. 열람기는 네트워크 fetch 없이 로컬 상대 경로 SVG와 내장 데이터만 사용한다.
- 첫 `npm run check`는 통과했으나 Tailwind가 보관한 MCP 생성 코드를 스캔하여 CSS 경고 15개를 발생시켰다. `src/app/globals.css`에 이 자료 폴더만 `@source not`으로 제외해 원본 보존과 실제 앱 CSS 생성을 분리했다. 검사 우회가 아니라 비애플리케이션 자료의 스캔 경계 지정이다.
- CSS 스캔 경계 수정 후 `npm run check` 통과: format, ESLint, TypeScript, architecture, comments, Apps Script artifact, 검사 도구 테스트 7개, 단위 테스트 208개, 프로덕션 빌드, 브라우저 테스트 21개. 실제 외부 저장 테스트 5개는 설정에 따라 skipped. 보관 MCP 코드에서 발생하던 CSS 경고 15개는 재빌드에서 사라졌다.
- SVG 추출 도구를 임시 복사본에서 실행해 11개 SVG/4,606개 텍스트를 다시 추출했고, 저장된 모든 텍스트 JSON과 내용이 일치했다.
- 마지막 검증 기록 갱신 뒤 문서 포맷 검사를 별도로 통과했다. 이 기록은 자료 수집 검증 시점의 결과이며, 앱 기능 구현·운영 배포 검증을 포함하지 않는다. 이후 출하·리뷰 상태는 Git 이력과 PR에서 확인한다.
